# talos-trades.com

The public website for Talos-Trades LLC. Plain static HTML served by GitHub Pages.

- `index.html` is the whole site.
- `CNAME` tells GitHub Pages the custom domain (talos-trades.com).
- `logo.png`, `favicon.png`, `apple-touch-icon.png` come from the Talos-Trades badge.

Site rules: no customer names, no prices until set, no claims Talos can't back up.
