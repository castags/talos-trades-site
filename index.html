How it talks

No source, no answer

A confident wrong answer on a job costs more than no answer. So Talos only gives code sections, specs and part numbers it can point to, and it says which book and edition they came from.

TechWhat's the part number for the igniter on this unit?
TalosI can see the unit, but I don't have its parts list in my documents, so I can't give you a part number. If you can get a clear photo of the rating plate, I'll look up the model.

What it does

Built for the work in front of you

Photo

Name the part

Take a photo of fittings, valves or equipment. A detector trained on job-site photos boxes and names the parts. Readable print, like a rating plate, helps pin down the make and model.

Code

Look up the code

Code answers come from the code books loaded for your area, labeled by edition. If the adopted code and a manufacturer's manual disagree, Talos says so.

Parts & manuals

Find the right manual

Part numbers come from parts tables, not memory. Fault codes name the manual and page they came from.

Math

Work the numbers

Trade math is done by built-in calculators and table lookups. The AI explains the result. It doesn't do the arithmetic in its head.

House rules

How Talos is built

  • Facts come from documents.Code books, manuals and parts tables. The AI explains; it doesn't make things up.
  • It says when it doesn't know.No source means no code section, spec or part number.
  • Your shop's data stays yours.Each shop runs on its own private setup, so your photos and job notes aren't shared with other shops.
  • Tested before it changes.Every change to how Talos answers is graded against trade question sets before it goes live.
